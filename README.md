# DSA Assignment Projects

This repository, **dsa_assignment**, contains a collection of C programs implementing fundamental Data Structures and Algorithms. Each project is designed to demonstrate core computer science concepts including memory management, recursion, graph theory, and algorithmic complexity.

---

## 📂 Project Directory

| Task # | Project Name | Key Concepts |
| :--- | :--- | :--- |
| **01** | **Parentheses Balancer** | Stack (LIFO), String Parsing |
| **02** | **Infix to Postfix** | Shunting-yard Algorithm, Expression Evaluation |
| **03** | **Linked List Reverse** | Singly Linked List, Recursive Traversal |
| **04** | **Doubly Linked List** | Bidirectional Pointers, Node Deletion |
| **05** | **Graph Traversals** | Adjacency Matrix, BFS (Queue), DFS (Recursion) |
| **06** | **Heap Builder** | Binary Heaps, Max-Heap/Min-Heap Properties |
| **07** | **Dijkstra's Algorithm** | Shortest Path, Greedy Algorithms, Weighted Graphs |
| **08** | **Sorting Comparison** | Bubble, Selection, Insertion, and Merge Sort |

---

## 🛠️ Data Structures Implemented

### 1. Linear Data Structures
* **Stacks**: Used for expression balancing and evaluation.
* **Singly Linked Lists**: Demonstrating dynamic memory allocation and recursive traversal.
* **Doubly Linked Lists**: Highlighting bidirectional node navigation and complex pointer manipulation.

### 2. Non-Linear Data Structures
* **Graphs**: Represented via Adjacency Matrices.
* **Heaps**: Implementing Complete Binary Trees using arrays to satisfy Max/Min heap properties.
